# 临时产品导入器设计

## 定位

`backend/app/scripts/import_products_csv.py` 是产品目录整理期间的临时工具。它只处理 `products.csv`，不处理资产、事件或愿望单；管理界面完成后可以替换或删除。

## 输入与处理链路

```text
products.csv
  -> 行与枚举校验
  -> 完整产品身份匹配
  -> 新建产品 / 更新同身份产品的补充字段
  -> products
```

产品身份由以下字段共同组成：厂商、来源类型、产品线、模型名称、版本/配色。空值也是身份的一部分。

必填字段：模型名称。

可选字段：厂商、来源类型、产品线、版本/配色。

## 明确拒绝的情况

- CSV 列数不正确。
- 模型名称为空。
- 日期、资产、事件、收藏分组等非产品字段出现在本导入流程中。

导入器不创建资产、不创建愿望单；详情与编号不从本批 CSV 写入，资料来源必须通过命令参数显式指定。

## 已知边界

修改产品身份字段会使该行无法匹配原记录，并被当作新产品候选。这是没有用户可见稳定记录引用时的必然限制；在产品编辑界面完成前，不应把 CSV 当成批量改名工具。

## 用法

```bash
docker compose exec api python -m app.scripts.import_products_csv /app/imports/products.csv --source 初始化测试
```
